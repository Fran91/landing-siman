# Landing Page de Promociones — Siman El Salvador

Proyecto final: landing page para promocionar descuentos y eventos exclusivos de Siman en El Salvador.

## Páginas
- `index.html` — Inicio: hero, beneficios, promociones destacadas y formulario de suscripción.
- `promociones.html` — Catálogo de promociones vigentes.
- `eventos.html` — Eventos exclusivos (Noche Siman, Día de la Madre, Navidad).

## Diseño
- **Tipografías:** Playfair Display (títulos) y Poppins (texto), desde Google Fonts.
- **Paleta de colores:**
  | Color | Hex | Uso |
  |---|---|---|
  | Rojo | `#C8102E` | Color principal, botones |
  | Rojo oscuro | `#8E0B20` | Hover, degradados |
  | Dorado | `#F2B705` | Ofertas y destacados |
  | Negro | `#1D1D1F` | Texto, secciones oscuras |
  | Crema | `#FFF7F0` | Fondo general |
  | Rosa claro | `#FFE9E3` | Fondos suaves |
- **Responsive:** CSS Grid/Flexbox con puntos de quiebre en 900px (tablet) y 640px (celular), menú hamburguesa en móvil.
- **Imágenes:** ilustraciones SVG en la carpeta `img/`.
